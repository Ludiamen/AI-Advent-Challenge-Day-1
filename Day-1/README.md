# Day-1 — запрос к LLM через API

Минимальный проект: отправляет запрос в LLM (DeepSeek, `deepseek-v4-flash`),
получает ответ и выводит его в консоль (CLI) или в браузере (Web).

## Структура

| Файл | Назначение |
|------|------------|
| `llm_client.py` | Ядро: функция `ask(prompt)` — один HTTP-запрос к API, возврат текста |
| `cli.py` | Консольный интерфейс (разовый запрос или диалог) |
| `web.py` + `templates/index.html` | Веб-интерфейс на Flask (одна страница) |
| `.env.example` | Шаблон конфигурации; копируется в `.env` |

## Установка

```bash
# Ubuntu: команда называется python3 (пакеты python3 + python3-venv)
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # затем вписать свой ключ в .env
```

После `source .venv/bin/activate` внутри окружения доступна и команда `python`.
Без активации используйте `.venv/bin/python`.

## Запуск

CLI:

```bash
python cli.py "Привет! Кто ты?"
python cli.py                     # интерактивный режим
```

Web:

```bash
python web.py                     # http://127.0.0.1:5000
```

## Безопасность

- Ключ читается только из переменной окружения `DEEPSEEK_API_KEY` (через `.env`),
  в коде его нет.
- `.env` внесён в `.gitignore` — реальный ключ не попадёт в git.
- В репозиторий коммитится только `.env.example` с плейсхолдером.
- У HTTP-запроса задан таймаут; ключ не логируется и не отображается в ошибках.
- Flask запускается на `127.0.0.1` с `debug=False` (без внешнего доступа и отладчика).
- Если ключ скомпрометирован — отзовите его в панели DeepSeek и выпустите новый.
