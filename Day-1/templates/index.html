Длина ответа: выберите пресет ({% for n in length_presets %}{{ n }}{{ ", " if not loop.last }}{% endfor %} слов) или впишите своё число в поле «…или своё число слов» — оно переопределяет пресет. Допустимо 1–2000 слов; при неверном значении форма покажет ошибку.

Метрики под ответом: finish_reason=stop — ответ завершён по маркеру END; length — упор в max_tokens. reasoning — сколько токенов ушло на скрытое рассуждение модели.

Примеры:

  • Запрос «Чем полезна ходьба?», профиль {{ strict_profile }}, формат {{ formats.keys()|list|first }}, длина 50 — короткий список.
  • Тот же запрос, формат абзац, своё число слов 200 — развёрнутый абзац.
  • Тот же запрос, формат резюме, длина 10 — одно предложение.
  • Профиль {{ profiles[0] }} — тот же запрос без каких-либо рамок, для сравнения.

Сравнить «{{ profiles[0] }}» и «{{ strict_profile }}» на одном запросе в консоли: python compare.py "Чем полезна ходьба?"
